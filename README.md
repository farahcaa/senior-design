## Which files do I edit?

Edit Markdown sources; PDFs are submission exports. D0, D1 and D2 are separate required design stages, not duplicate copies. Assignment 8 explicitly requires Tasklist.md at the root as well as the same tasks inside the plan.

Edit [the Assignment 8 plan](Planning/Assignment_8_Plan.md) directly. When task statements or owners change, update the required root task list too. Export the Markdown plan to PDF for submission.

## Folder guide

- **Team/**: biographies and team contract.
- **Requirements/**: user stories and acceptance criteria.
- **Design_Diagrams/**: D0, D1, D2 and their submission PDFs.
- **Planning/**: task schedule, effort matrix, feature checklist and planning PDF.
- **Ethics/**: ethics PDF, constraints source and previous constraints PDF.
- **Presentation/**: slide assignments, with deck and feedback files to follow.
- **code/**: application code.

Ethics_Statement.md and Tasklist.md stay at the root as explicitly required by the assignment prompts. NOTICE.md supports the ethics statement. The output/ directory has been removed. Older PDFs retain historical source paths; use this README to find current files.
